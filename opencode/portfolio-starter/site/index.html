About

I build autonomous agents that run real tasks while I sleep. My current focus is loop engineering — designing agents that watch, react, and remember without human intervention. I work primarily with OpenCode and Claude Code, and I'm learning to make agents that are useful, not just impressive.

Every project I build is a loop: something that starts, observes its environment, makes a decision, and acts — all without me touching a keyboard.

Projects

ISS Space Station Tracker

A live tracker that shows the International Space Station position every minute. Built as a class assignment for the Loop Engineering Crash Course. I wrote the bash loop script that runs the fetch on a schedule, and adapted the Python position fetcher to work on Windows. The loop runs independently — it fetches, formats, and displays the coordinates without any input from me.

Morning Brief Agent

An agent that scans code comments across a codebase and generates a daily summary of what needs attention. Uses a spine file to remember what it reported yesterday, so it can highlight what changed. Built as a class assignment. The loop wakes up each morning, reads the code, compares against its memory, and writes a brief — a small example of an agent that remembers.

Doorbell Loop

An event-driven loop that reviews pull requests on GitHub automatically. No human starts it — a PR event triggers the review. I set up the GitHub Actions workflow and token authentication so the agent can read diffs, comment on issues, and post its findings. The loop listens for events and responds without anyone pressing a button.
